Dong Wook Shin — Signature Assets

Two designs are included:
A = clean signature, no underline
C = clean signature with a restrained underline

For each design:
- dong-wook-shin-X.svg: vector path, fill=currentColor (best for inline SVG in HTML)
- dong-wook-shin-X-white.svg: white vector for dark backgrounds
- dong-wook-shin-X-dark.svg: dark gray vector for light backgrounds
- dong-wook-shin-X.png: 1600 x 400 transparent PNG (white lettering)

HTML examples:
<img src="assets/dong-wook-shin-A-white.svg" alt="Dong Wook Shin">
<img src="assets/dong-wook-shin-C-dark.svg" alt="Dong Wook Shin">

For currentColor to inherit from CSS, inline the SVG markup in the HTML instead of loading it with an img tag.
The SVGs are path-based vector artwork and do not require the font to be installed.
