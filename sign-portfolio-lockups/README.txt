DONG WOOK SHIN — PORTFOLIO SIGNATURE LOCKUPS

Two horizontal lockups are included. Both use a clean script signature on the left and a compact, bold sans-serif PORTFOLIO wordmark in orange (#F67D06) on the right.

DESIGN 1 — Basic signature + orange PORTFOLIO
- The signature has no underline.

DESIGN 3 — Orange underline accent + orange PORTFOLIO
- The signature is accented with a restrained orange underline.

Each design has exactly four deliverables:
- dong-wook-shin-portfolio-N.svg: SVG with currentColor signature and orange PORTFOLIO. Best when the SVG markup is inline in HTML so CSS color can control currentColor.
- dong-wook-shin-portfolio-N-white.svg: white signature, for dark backgrounds.
- dong-wook-shin-portfolio-N-dark.svg: dark-gray signature (#292929), for light backgrounds.
- dong-wook-shin-portfolio-N.png: transparent PNG, white signature + orange PORTFOLIO, 2320 x 520 pixels.

The PORTFOLIO lettering is converted to vector paths; it does not depend on an installed font. The signature is also path-based. All SVGs have transparent backgrounds.

HTML examples:
<img src="assets/dong-wook-shin-portfolio-1-white.svg" alt="Dong Wook Shin Portfolio">
<img src="assets/dong-wook-shin-portfolio-3-dark.svg" alt="Dong Wook Shin Portfolio">

Color guidance:
- Dark background: use the -white.svg file.
- Light background: use the -dark.svg file.
- PNG is the white-signature version for dark backgrounds.
